Overview:
---------
This is a responsive movie library web application built with:
- Vue.js 3
- HTML5 & CSS3
- GSAP (for transitions)
- TVmaze API (for movie search)

Features:
---------
- Search for TV shows using TVmaze API
- Add selected shows to a dynamic grid
- View static movie cards
- Responsive design for mobile, tablet, and desktop
- Contact form with basic validation
- Sidebar menu for mobile navigation
- Light GSAP-based media slideshow (image + video)

File Structure:
---------------
(root)
 index-ltr.html        # Main HTML file (Left-to-Right layout)
 script.js             # Vue logic for slideshow, navbar, movie search
 style-ltr.css         # LTR-specific styles
 Assets                # Contains logos, icons, videos, and images

How to Use:
-----------
1. Open index-ltr.html in a modern browser.
2. Use the search bar to find and add shows to your custom movie grid.
3. Browse existing movie cards.
4. Use the contact form to simulate reaching out.

Dependencies:
-------------
- Vue.js 3 CDN: https://unpkg.com/vue@3
- GSAP CDN: https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js
- TVmaze API: https://api.tvmaze.com/search/shows?q=
